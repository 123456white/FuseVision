- 创建项目功能，同步创建项目信息载入文件xxx.fvproj

<h3 id="模型管理功能">模型管理功能</h3>
- 创建模型功能，同步创建信息载入文件 xxxx.fvdl
- 四种深度学习任务类型，创建时按类型生成不同目录结构和 data.yaml：

| 任务类型 | 标签格式（每行） | 目录结构 | 是否需要 labels/ |
|---------|-----------------|---------|:---:|
| 实例分割 | `class_id x1 y1 x2 y2 ...`（多边形顶点） | images + labels 并列 | 是 |
| 自由矩形检测 | `class_id x_center y_center width height` | images + labels 并列 | 是 |
| 非自由矩形(OBB)检测 | `class_id x1 y1 x2 y2 x3 y3 x4 y4`（四角点） | images + labels 并列 | 是 |
| 异常检测(OK/NG分类) | 无标签文件，由文件夹名称定义 | train/OK, train/NG, val/OK, val/NG | **否** |

**数据格式细节：**

- **实例分割**：归一化多边形顶点坐标（0-1），每个分割至少3个点
- **自由矩形检测**：归一化中心点+宽高（0-1）
- **OBB检测**：归一化四个角点（0-1），支持任意旋转方向
- **异常检测**：无 .txt 标签文件，图像按 OK/NG 子文件夹分类

**目录结构差异：**

```
# YOLO 布局（实例分割/自由矩形/OBB）
dataset/
├── images/
│   ├── train/
│   └── val/
└── labels/
    ├── train/
    └── val/

# 分类布局（异常检测）
dataset/
├── train/
│   ├── OK/
│   └── NG/
└── val/
    ├── OK/
    └── NG/
```

**data.yaml 差异：**
- 检测/分割/OBB：指定 `path`、`train: images/train`、`val: images/val`、`nc`、`names`
- 异常检测：指定 `path`、`train: train`、`val: val`，类别由文件夹名称自动识别
- .fvdl 中通过 `dataset_layout` 字段区分：`"yolo"` / `"classification"`

- 打开模型功能，可选择对应路径的fvdl文件进行读取
